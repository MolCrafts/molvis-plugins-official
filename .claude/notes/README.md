# `.claude/notes/`

Passive project knowledge for agents. Long-lived; outlives individual features.

| File | Role |
|------|------|
| `notes.md` | Evolving decisions captured by `/mol:note` |
| `architecture.md` | Module / package blueprint (`/mol:map` fills this) |
| `open-questions.md` | Unresolved choices from bootstrap or planning |
| `release.md` | How we ship tags and what must be committed |

Do **not** put active specs here — those live in `.claude/specs/`.
Do **not** put public user docs here — those live in `README.md` / `docs/`.
